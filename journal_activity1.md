# Activity 1

## 1. Storage and Accessibility
Efficient file organisation makes research materials easy to locate and retrieve for yourself and collaborators. It reduces risks of lost, duplicated or messy files, maintains research transparency, and supports smooth version control in Git.

## 2. File Storage Methods
General research documents and literature can be stored in the public GitHub repository. Sensitive data such as interview transcripts and participant consent forms need special access controls, as they contain personal identifiable information and must be kept private.
